Inside the device

The firmware on the guard's belt unit: a FreeRTOS application in C++ on an ESP32-S3 with a 4G modem.

Offline-first, encrypted

When the network drops, SOS and checkpoint events go to an AES-256-GCM encrypted SD buffer and are replayed in order once it returns. Agents can still log in with their badge while offline.

RG2:<nonce>:<ciphertext>:<tag> AES-256-GCM · one key per data domain · master key never leaves the chip

Man-down detection

Fall and prolonged-immobility detection on an MPU6050, using the same calibrated algorithm as the mobile app. Supervisors tune it from the web dashboard.

MPU6050 · I²C

4G with GSM fallback

LTE Cat-1 modem that switches to GSM based on coverage. MQTT runs over TLS.

SIM7670G · TinyGSM

Location without a fix

GNSS positioning, with a cell-tower fallback resolved on the server when there is no satellite fix.

GNSS · Cell-ID

Over-the-air updates

New firmware is downloaded and flashed in the field, triggered over MQTT, and never cut off by deep sleep.

OTA · MQTT trigger

NFC checkpoints

A PN532 reader validates patrol tags and agent badges. The OLED shows the current round and the time left.

PN532 · SSD1306 OLED

Real-time and low-power

One FreeRTOS task per subsystem (modem, GNSS, NFC, display, BLE, OTA) with mutex-protected shared state, and deep sleep when idle to save battery.

FreeRTOS · mutexes · deep sleep · BLE
